## 🌟 주요 특징

- **Spline 3D 로봇 인터랙션**: 마우스 커서를 실시간 추적하는 3D WebGL 모델 탑재 (전체화면 모드 및 모바일 스크롤 보호 모드 지원)
- **미니멀리즘 럭셔리 다크/라이트 모드**: 포인트 컬러 블루 (`#0C4DA2`)와 완벽한 고대비 타이포그래피
- **실무 프로젝트 아카이브 (12건)**:
  - `.NET WPF Visa 신청 및 처리 관리 시스템` (C사, 하드웨어 바코드/POS/Telerik Report)
  - `.NET WPF 차세대 ERP 시스템` (M사 30인 규모 모듈 PL, 외교부 여권/OCR/EF Core)
  - `.NET RPA 엔진 및 기업 맞춤형 프로세스` (Chrome 조작, 100% 납기 준수)
  - `C# WPF IMGPuzzle`, `WinForm YeziPos`, `YOLOv5 음식 영양 AI` (대상 수상) 등
- **풀스택 기술 스택 매트릭스 & 실시간 검색**
- **모바일 완벽 반응형 디자인**

## 🚀 로컬 실행 방법 (Local Development)

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 브라우저에서 확인
# http://localhost:3000
```

---

## 📦 프로덕션 빌드 (Production Build)

```bash
npm run build
```

---

## ☁️ 배포 가이드 (Vercel)

1. GitHub 레포지토리(`https://github.com/attSmileHappy/PortfolioWebsite`)에 코드 푸시
2. [Vercel](https://vercel.com) 로그인 후 **"Add New..."** → **"Project"** 클릭
3. `PortfolioWebsite` 레포지토리 **Import**
4. 프레임워크 프리셋: `Vite` (자동 감지)
5. **Deploy** 버튼 클릭하여 완료!
