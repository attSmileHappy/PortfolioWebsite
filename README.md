# 김예지 (Yeji Kim) · 인터랙티브 개발자 포트폴리오

> **"WPF, 자동화부터 인공지능까지 — 끊임없이 배우며 성장하는 개발자, 김예지입니다."**

본 프로젝트는 .NET WPF 엔터프라이즈 데스크톱 아키텍처, 윈도우 RPA 로봇 프로세스 자동화 파이프라인, 그리고 딥러닝/컴퓨터 비전 모델 개발 역량을 집약한 **인터랙티브 웹 포트폴리오**입니다.  
제품 런칭 페이지 스타일의 에디토리얼 레이아웃과 **Spline 3D 로봇 캐릭터의 시네마틱 줌아웃 연출**을 적용하여 개발 전문성과 인터랙티브 경험을 동시에 전달하도록 구현되었습니다.

## 🌟 주요 기능 및 특징 (Key Features)

- **인터랙티브 Spline 3D 히어로 섹션**:
  - 네이티브 Spline 3D 씬(`nexbotrobotcharacterconcept`)을 100vh 풀스크린으로 임베드.
  - 페이지 로드 시 카메라가 서서히 뒤로 빠지는 시네마틱 줌아웃 연출(`scale(1.26)` → `scale(1)` / 2.2초 소요).
  - 인트로 애니메이션 완료 후 마우스/포인터 이벤트가 상시 활성화되어 사용자가 3D 로봇을 자유롭게 회전 및 조작 가능.
  - 시스템 접근성(`prefers-reduced-motion`) 설정을 감지하여 모션 감소 모드 자동 지원.

- **하이엔드 에디토리얼 디자인 시스템**:
  - 부드러운 웜 뉴트럴 캔버스 컬러(`#FAF8F5`)와 딥 차콜 타이포그래피(`#141413`), 시그니처 옐로우 포인트(`#FFE600`) 조화.
  - *Plus Jakarta Sans*와 *Noto Sans KR* 폰트를 조화롭게 적용하여 영문과 국문 모두 높은 가독성 제공.
  - 박스형 뱃지 남용을 지양하고 깔끔한 비박스형 메타데이터(`·` 구분자)를 적용한 세련된 여백 중심 구조.

## 🚀 로컬 개발 환경 실행 방법 (Getting Started)

### 사전 요구 사항
- Node.js 18 버전 이상 (Node 20+ 권장)
- npm (또는 pnpm / yarn)

### 설치 및 구동

```bash
# 1. 저장소 복제 (Clone)
git clone https://github.com/attSmileHappy/portfolio.git
cd portfolio

# 2. 의존성 패키지 설치
npm install

# 3. 로컬 개발 서버 시작
npm run dev
```

터미널에 출력되는 로컬 주소(`http://localhost:3000` 또는 `http://localhost:5173`)로 접속하시면 즉시 확인하실 수 있습니다.

## 🏗️ 프로덕션 빌드 (Production Build)

정적 배포용 프로덕션 번들을 생성합니다:

```bash
npm run build
```

빌드 결과물은 `dist/` 폴더에 생성되며, 로컬에서 빌드 결과물을 미리 테스트하려면 아래 명령어를 사용합니다:

```bash
npm run preview
```
